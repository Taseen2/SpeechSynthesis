# The Voiceinator 5000 🎙️

A fun, interactive speech synthesis application built as part of the JavaScript30 challenge. It allows users to convert text to speech using various voices, with adjustable rate and pitch.

## Features

- **Text-to-Speech:** Convert any typed text into spoken words.
- **Voice Selection:** Filtered list of voices including English and Hindi.
- **Adjustable Controls:** Change the speed (rate) and tone (pitch) of the voice.
- **Dark Mode:** Modern dark theme by default, with a manual toggle for light mode.
- **Persistence:** Remembers your theme preference across sessions.

## Demo

Just open `index.html` in your favorite web browser!

## Built With

- **HTML5:** Semantic structure and range inputs.
- **CSS3:** Custom styling with CSS Variables and Dark Mode support.
- **JavaScript:** Speech Synthesis API for voice generation and DOM manipulation for interactivity.

## How to Use

1. **Select a Voice:** Choose from the available English or Hindi voices in the dropdown.
2. **Adjust Sliders:** Use the "Rate" and "Pitch" sliders to customize the sound.
3. **Enter Text:** Type whatever you want the Voiceinator to say in the text area.
4. **Speak/Stop:** Click "Speak" to hear the text or "Stop" to cancel the speech.
5. **Theme Toggle:** Use the switch in the top-right corner to change between dark and light modes.
